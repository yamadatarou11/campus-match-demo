Campus Match 外部公開ガイド
============================

目的
----
PCの電源を切っても、スマホや友達の端末からアプリを開けるようにクラウドへ公開します。

現在の状態
----------
ローカル用:
http://192.168.11.6:4175/index.html

このURLはPCが起動中、同じWi-Fi内だけで使えます。
PCを消しても使えるようにするには、Renderなどのクラウドへデプロイしてください。

Renderで公開する手順
--------------------
1. GitHubにこのフォルダをリポジトリとしてアップロードします。
2. RenderでNew Web Serviceを作成します。
3. GitHubリポジトリを選びます。
4. Start Commandは次です。

python server.py

5. Health Check Pathは次です。

/api/health

6. デプロイ完了後、Renderが発行するURLをスマホや友達に送ります。

例:
https://campus-match-demo.onrender.com/index.html

データベース
------------
SQLiteは data/campus_match.db に作成されます。
Renderなどのクラウドでは、永続ディスクを設定しない場合、再デプロイや再起動でDBが初期化される可能性があります。
本格運用ではSupabaseやPostgreSQLなどの外部DBへ移行してください。

デプロイ済みURLの確認
--------------------
ブラウザで次を開いて ok が返ればサーバーとDBは起動しています。

/api/health

注意
----
この構成はデモ公開向けです。
本番運用ではHTTPS、パスワードハッシュ化、大学メールの実送信認証、通報監査ログ、利用規約同意ログが必要です。
