Campus Match 使い方説明書
=========================

概要
----
Campus Match は、大学生が友達づくり・恋人探し・勉強仲間探しを行うためのブラウザアプリです。
この版はデモ運用向けの静的プロトタイプで、サーバーやデータベースなしで動作します。

起動方法
--------
1. index.html をブラウザで開きます。
2. 最初にログイン画面が表示されます。
3. 仮アカウントでログインするか、新規登録からアカウントを作成します。
4. ログイン後、「探す」画面で候補学生を確認します。
5. 「いいね」を押すとマッチ一覧とメッセージ画面に相手が追加されます。

iPhoneでデモする場合
--------------------
同じフォルダの IPHONE_DEMO_GUIDE.txt を確認してください。
PCでローカルサーバーを 0.0.0.0 に向けて起動し、iPhoneのSafariからPCのIPv4アドレスへアクセスします。
SQLiteデータベース付きで起動する場合は DATABASE_GUIDE.txt を確認してください。

App Store提出準備
-----------------
App Storeで配信するには、このWebデモをiOSアプリとしてビルドし、本番バックエンドとApple Developer Programの設定が必要です。
提出準備用の資料は以下にまとめています。

- APP_STORE_RELEASE_CHECKLIST.txt
- IOS_IMPLEMENTATION_PLAN.txt
- PRIVACY_POLICY.txt
- TERMS_OF_SERVICE.txt

仮アカウント
------------
メール: demo@campus.ac.jp
パスワード: demo1234

連番デモアカウントも30個あります。
メール: demo1@campus.ac.jp から demo30@campus.ac.jp
パスワード: demo1 から demo30
例: demo7@campus.ac.jp / demo7

全アカウントの一覧は DEMO_ACCOUNTS.txt にまとめています。

アカウント作成
--------------
ログイン画面の「新規登録はこちら」から登録を開始します。
大学メールは .ac.jp または .edu のメールアドレスのみ登録できます。
登録は、大学メール認証、ニックネーム、性別、学年・年齢の順に画面が切り替わります。
大学名、学部・専攻、趣味、探している相手、タイプは任意項目です。スキップして後からプロフィールで入力できます。
このデモではメール送信の代わりに、画面上に6桁のデモ認証コードを表示します。
このデモではアカウント情報をブラウザの localStorage に保存します。
本番運用ではパスワードを平文保存せず、必ずサーバー側で安全にハッシュ化してください。

主な画面
--------
探す:
候補プロフィール、タグ、見送り、気になる保存、いいねを操作できます。
男性アカウントでログインした場合、女性候補のみ表示されます。
デモ用に完成済みの女性プロフィールを複数登録しています。

いいね:
気になる保存やハートを押した相手が一覧表示されます。データはブラウザの localStorage に保存されます。

チャット:
ハートでマッチした相手が一覧表示されます。相手を選ぶと簡易チャットを送信できます。

プロフィール:
自分の写真、ニックネーム、大学、学部・専攻、趣味、探している相手、タイプ、自己紹介、利用目的を編集できます。

安全:
大学メール認証、通報、ブロック、個人情報投稿チェックなど、運用時に必要な安全設計を確認できます。

運用メモ
--------
- デモデータは app.js の candidates、events、moderationChecks で管理します。
- 仮アカウントと登録アカウントは localStorage の campusAccounts に保存されます。
- マッチとメッセージは localStorage の campusMatches に保存されます。
- 保存データをリセットする場合は、ブラウザの開発者ツールから localStorage を削除してください。
- 本番化する場合は、大学メール認証、本人確認、通報対応、利用規約、プライバシーポリシー、年齢確認、監査ログを追加してください。
