iPhoneデモ用ガイド
==================

目的
----
Campus Match をiPhoneのSafariで開き、ログイン、探す、いいね、チャット、プロフィール編集をデモするための手順です。

1. PC側でデモサーバーを起動
--------------------------
PowerShellでこのフォルダを開き、次のコマンドを実行します。

SQLiteデータベース付きで起動する場合:
python server.py 4175

通常の静的デモだけで起動する場合:
python -m http.server 4174 --bind 0.0.0.0

すでに別のサーバーが起動している場合でも、4174番ポートなら別枠で起動できます。
Windowsファイアウォールの確認が出た場合は、同じWi-Fi内のiPhoneから見るために許可してください。

2. PCのIPアドレスを確認
----------------------
PowerShellで次のコマンドを実行します。

ipconfig

Wi-Fiアダプターの「IPv4 アドレス」を確認します。
例: 192.168.1.23

3. iPhoneで開く
---------------
iPhoneをPCと同じWi-Fiに接続します。
Safariで次の形式のURLを開きます。

DB付きデモ:
http://PCのIPv4アドレス:4175/index.html

通常デモ:
http://PCのIPv4アドレス:4174/index.html

例:
http://192.168.11.6:4175/index.html

今回のPCで確認したURL:
http://192.168.11.6:4174/index.html

このURLをiPhoneのSafariで開いてください。LINEやChromeではなく、必ずSafariで開くと「ホーム画面に追加」が使いやすいです。

4. ホーム画面に追加
------------------
Safariでアプリを開いた状態で、画面下の共有ボタンを押します。
メニューから「ホーム画面に追加」を選びます。
名前が Campus Match になっていることを確認し、「追加」を押します。
ホーム画面に追加されたアイコンから起動すると、Safariのアドレスバーがないアプリ風の表示になります。

5. 仮アカウントでログイン
------------------------
メール:
demo@campus.ac.jp

パスワード:
demo1234

複数人でデモする場合は、次の連番アカウントを使えます。
メール: demo1@campus.ac.jp から demo30@campus.ac.jp
パスワード: demo1 から demo30
例: demo12@campus.ac.jp / demo12

全30件は DEMO_ACCOUNTS.txt を確認してください。

6. デモの流れ
------------
1. ログイン画面を見せる。
2. 仮アカウントでログインする。
3. 「探す」でカードを確認する。
4. ハートを押してマッチする。
5. 「いいね」で保存した相手を確認する。
6. 「チャット」でマッチ相手を選んでメッセージを送る。
7. 「プロフィール」で写真、学部・専攻、趣味、探している相手、タイプを編集する。

注意
----
- このデモはブラウザ内のlocalStorageにデータを保存します。
- iPhoneとPCが同じWi-Fiにいない場合、iPhoneからPCのURLを開けません。
- PCがスリープするとデモサーバーも止まります。
- 本番運用ではHTTPS、サーバー認証、パスワードのハッシュ化、正式な大学メール認証が必要です。
